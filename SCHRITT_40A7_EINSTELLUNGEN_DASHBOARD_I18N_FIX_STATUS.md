# Schritt 40a7 – Einstellungen Dashboard- und Übersetzungsfix

- Modul **Einstellungen** in der Dashboard-Modulübersicht ergänzt.
- Modulname wird über den zentralen Übersetzungsschlüssel `settings` aufgelöst.
- Deutsch: **Einstellungen**
- Englisch: **Settings**
- Navigation, Login-Auswahl und Modulfehlerrahmen verwenden denselben übersetzten Modulnamen.

## Test
1. Sprache Deutsch: Login-Dialog und Navigation zeigen „Einstellungen“.
2. Sprache Englisch: Login-Dialog und Navigation zeigen „Settings“.
3. Dashboard öffnen: Einstellungen erscheint in der Modulübersicht.
4. Direktlogin in Einstellungen erneut prüfen.
