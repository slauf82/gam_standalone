# 40k37e56a7 – Geräteworkflow responsiv nebeneinander

- Geräteworkflow-Schritte werden auf breiten und mittleren Ansichten nebeneinander dargestellt.
- Bei fehlender Breite erfolgt ein automatischer mehrzeiliger Umbruch.
- In mittleren Ansichten beginnt die zweite Workflow-Zeile leicht versetzt.
- Verbindungspfeile verlaufen horizontal; auf schmalen Ansichten wechselt der Workflow automatisch zurück zur vertikalen Darstellung.
- Reihenfolge, Navigation und fachliche Workflow-Logik bleiben unverändert.
- Basis: 40k37e56a6.
