# 40k36q12 – macOS-Softwarebereich immer sichtbar

- Der macOS-Bereich `Software` wird nach vorhandener macOS-Inventarisierung nicht mehr aufgrund einer leeren strukturierten Softwareliste ausgeblendet.
- Bei 0 strukturierten Softwareeinträgen zeigt GAM einen klaren Warn-/Diagnosehinweis.
- `Installierte Software`, `Software-Werkzeuge` und `Softwareupdates` bleiben sichtbar.
- Die vollständigen macOS-Inventardaten bleiben darunter als Vergleich erhalten.
- Ziel: Erkennung, Speicherung und API-Übernahme der Softwaredaten können eindeutig voneinander unterschieden werden.
