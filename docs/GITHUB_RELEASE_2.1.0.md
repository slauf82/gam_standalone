# GAM Standalone v2.1.0

Die stabile Version **GAM 2.1.0** vereint plattformübergreifende Geräteerkennung und Inventarisierung mit konsolidierter Geräteverwaltung. Die aktuelle Version stabilisiert Windows/WinRM (inklusive SSPI), Linux/SSH, die Quellendarstellung und das Layout umfangreicher Inventarisierungsdaten.

**English:** GAM Standalone v2.1.0 consolidates cross-platform discovery and inventory, including Windows/WinRM with SSPI fallback, Linux/SSH, improved source display, and stable device-row layouts.

Details: `docs/RELEASE_NOTES_2.1.0_DE.md` / `docs/RELEASE_NOTES_2.1.0_EN.md`.
