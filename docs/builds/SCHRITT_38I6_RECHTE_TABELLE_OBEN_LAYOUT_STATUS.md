# Schritt 38i6 – Rechte-Tabelle oben / Layout-Korrektur

## Ziel
Die Rechte-Tabelle im Benutzer/Rechte-Dialog war nach 38i5 zu schmal an der Seite positioniert. In 38i6 wird sie als breite Übersicht oberhalb der Eingabefelder dargestellt.

## Änderungen
- Rechte-Tabelle im Rechte-Tab steht jetzt oben über den Eingabefeldern.
- Tabelle nutzt die volle Dialogbreite.
- Spalten: ID, Anwendung, Gesellschaft, Rolle, Aktion.
- Eingabefelder Anwendung, Anwendung manuell, Gesellschafts-ID und Rolle stehen darunter.
- Das Layout folgt wieder dem GDS-Muster: Tabelle zuerst, Details/Bearbeitung darunter.
- Überlappungen werden weiterhin durch Mindestbreiten, Umbruch und saubere Grid-Abstände verhindert.

## Hinweis
Keine Datenbank- oder Backend-Änderungen.
