# Schritt 40k17 – Computer-Typ wiederhergestellt

- Die übrige Geräteklassifizierung aus 40k16 bleibt unverändert.
- Registrierte Geräte mit dem explizit gespeicherten Typ `Computer` werden wieder als Computer einsortiert.
- Eindeutige AVM-, Netzwerk-, Kamera-, Drucker- und Energiehinweise besitzen weiterhin Vorrang und verhindern Fehlklassifizierungen.
- Unklare Geräte ohne gespeicherten Computertyp bleiben weiterhin in einer neutralen Kategorie.
