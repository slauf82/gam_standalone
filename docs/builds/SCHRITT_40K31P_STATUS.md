# Schritt 40k31p – Reportlayout und Modulzustand

- Berichtsauswahl auf eine breite, einspaltige Listenansicht umgestellt.
- Geräteart erhält deutlich mehr Platz und bricht erst bei kleinen Bildschirmbreiten um.
- Auswahlzähler steht in einer eigenen rechten Spalte.
- Checkbox steht konsequent ganz rechts.
- Gerätearten werden als Badges mit Gerätesymbol dargestellt.
- Druck-/PDF-Layout verwendet dieselbe klare Spaltenstruktur.
- Das zuletzt geöffnete Modul wird in `gam_last_module_page` gespeichert und nach Aktualisierung oder neuem Build wieder geöffnet, sofern der Benutzer Zugriff darauf hat.
