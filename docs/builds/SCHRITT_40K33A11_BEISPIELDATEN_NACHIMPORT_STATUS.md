# Schritt 40k33a11 – Beispieldaten nachträglich importieren

- Gepflegte Preview-3-Beispieldatendatei ist fester Paketbestandteil.
- Freie Wahl bei der Ersteinrichtung: leere Praxis oder Beispieldatenbank.
- Nachträglicher Import unter Einstellungen → Datenbank.
- Nur Administrator/Superadministrator.
- Administrator, Passwort, 2FA, Passkeys und Rechte werden nicht ersetzt.
- Reproduzierbarer Import mit Warnung vor dem Ersetzen fachlicher Beispieldaten.
