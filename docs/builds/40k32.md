# 40k32 – Windows-Erkennung: erster Grundausbau

## Inhalt

- neue lokale Erkennungsquelle **Windows-Inventarisierung**
- PowerShell-/CIM-Abfrage ohne zusätzliche Zugangsdaten
- Erfassung von Computername, Windows-Edition, Version, Build, Architektur, Hersteller, Modell, BIOS-Seriennummer, Domäne/Arbeitsgruppe, angemeldetem Benutzer, IP- und MAC-Adresse
- Integration in Live-Trefferzählung, Discovery-Diagnose, Registrierung, Confidence-/Merge-Engine und Geräteklassifizierung
- eigener Schalter unter **Gerätemanager → Erkennungsquellen → Lokale Discovery-Quellen**
- eigener Windows-Quellenbadge
- auf Nicht-Windows-Systemen sauberer Status `übersprungen` statt Fehler

## Einordnung

Dieser Build bildet die belastbare lokale Basis von 40k32. Remote-Windows-Erkennung über WMI/WinRM, Active Directory, Intune oder MECM kann in den folgenden Ausbaustufen auf derselben Quelle und Diagnosearchitektur ergänzt werden.
