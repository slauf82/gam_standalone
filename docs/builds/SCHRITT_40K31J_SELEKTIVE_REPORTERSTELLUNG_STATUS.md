# Schritt 40k31j – Selektive Reporterstellung

## Umgesetzt

- Berichtsauswahl direkt im Reportbereich des Gerätemanagers
- Kategorien als aufklappbarer Auswahlbaum
- Auswahl kompletter Kategorien
- Auswahl einzelner Geräte
- „Alle auswählen“ und „Keine auswählen“
- Teilmarkierung einer Kategorie wird visuell als unbestimmter Checkbox-Zustand dargestellt
- Anzahl ausgewählter Geräte wird live angezeigt
- Qualitätsbericht, Maßnahmenliste sowie CSV-, HTML- und Druck/PDF-Ausgabe verwenden ausschließlich die ausgewählten Geräte
- Suche, Qualitätsfilter und Bestandsfilter wirken zusätzlich auf die Berichtsauswahl
- Auswahlbereich wird beim Drucken ausgeblendet

## Hinweis

Beim ersten Laden sind alle Geräte ausgewählt, sodass das bisherige Verhalten erhalten bleibt. Danach kann der Bericht gezielt eingeschränkt werden.
