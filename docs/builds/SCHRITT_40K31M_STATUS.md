# Schritt 40k31m – Kompakte Kategoriezeilen im Report

## Umgesetzt

- Kategoriebezeichnung steht unmittelbar links hinter dem Aufklapppfeil.
- Auswahlzähler wird verständlich als „(x von y)“ direkt hinter der Kategorie angezeigt.
- Das Auswahl-Häkchen bleibt allein am rechten Rand.
- Große ungenutzte Leerflächen zwischen Pfeil und Kategorie wurden entfernt.
- Lange Kategorienamen dürfen sinnvoll umbrechen, ohne nach rechts gedrängt zu werden.
- Das gleiche Layout wird ausdrücklich auch beim Drucken beziehungsweise PDF-Export erzwungen.
- Sonstige Funktionen von 40k31l wurden unverändert übernommen.

## Beispiel

`▼  Computer (6 von 6)                                      ☑`

## Paketregel

`dist` und `node_modules` sind nicht Bestandteil des Entwicklungspakets.
