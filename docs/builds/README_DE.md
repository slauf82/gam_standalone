# GAM 2.0

**Moderne Enterprise-Management-Plattform**

🇬🇧 **English:** [README.md](README.md)

## Überblick

GAM 2.0 ist der Nachfolger einer langjährig produktiv eingesetzten
Unternehmenssoftware. Ausgehend von der Migration einer
Java-EE-/JSF-/GlassFish-Anwendung entwickelte sich das Projekt zu einer
modernen Plattform mit deutlich erweitertem Funktionsumfang.

Kerntechnologien:

-   Java / Spring Boot
-   React + TypeScript
-   MariaDB
-   JWT, TOTP und WebAuthn Passkeys

## Highlights

-   Mehrsprachige Benutzeroberfläche
-   Unternehmensverwaltung
-   Workflow-Engine
-   Rechnungsadministration
-   Barrierefreie PDF-Erzeugung (PDF/UA)
-   WCAG-orientierte Dokumentenworkflows
-   ZUGFeRD / Factur-X
-   Mehrsprachige Vorlesefunktion
-   Reports und Exporte
-   Multi-Quellen-Geräteverwaltung
-   Modulare Architektur

## Multi-Quellen-Gerätemanager

Geräte werden nicht mehr ausschließlich manuell gepflegt. Informationen
aus mehreren Quellen werden zusammengeführt, abgeglichen und automatisch
in der zentralen Geräteverwaltung aktualisiert.

## Barrierefreiheit

-   PDF/UA-kompatible Dokumente
-   Getaggte PDFs
-   WCAG-orientierte Dokumentstruktur
-   Mehrsprachige Rechnungen
-   Vorlesefunktion in unterstützten Sprachen

## Architektur

Backend: - Spring Boot - REST-APIs - MariaDB

Frontend: - React - TypeScript - Vite

## Vision

GAM 2.0 ist eine langfristig ausgelegte Enterprise-Plattform für
Verwaltung, Workflows, Geräteinventarisierung und barrierefreie
Dokumentenerzeugung.
