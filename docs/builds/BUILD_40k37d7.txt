GAM Standalone v2.1.0 – Schritt 40k37d7
==========================================

Ziel
----
- MSYS2-UCRT64-Resolver um virtuelle Paketabhaengigkeiten/PROVIDES erweitern.
- Konkret kann damit z. B. mingw-w64-ucrt-x86_64-cc-libs ueber den von der Repository-Datenbank ausgewiesenen Provider aufgeloest werden, ohne den Provider hart zu raten.
- Bei mehreren Providern bricht GAM bewusst deterministisch ab statt still einen beliebigen Provider zu waehlen.
- Vollstaendige Runtime-Closure weiterhin aus der offiziellen MSYS2-UCRT64-Repository-Datenbank; jedes konkrete Paket wird gegen dessen SHA-256 verifiziert.
- ideviceinstaller 1.1.1-2 bleibt zusaetzlich hart gepinnt.
- Smoke-Test protokolliert jetzt auch den Prozess-Exitcode (dezimal + hex), damit Windows-Loaderfehler ohne stderr erkennbar werden.
- Fehlgeschlagene optionale IORegistry-Probes werden pro Prozess/UDID gemerkt und bei weiteren Inventarlaeufen nicht erneut bis zum Timeout abgefragt.
- Diagnostics All/WiFi/GasGauge/NAND bleiben unveraendert voll aktiv.
- Erweiterter Rohsnapshot: logs/apple-mobile-inventory-d7.json.
- Software-Inventarisierung bleibt: Software -> Quelle -> Softwareliste; keine Herkunft wird aus Bundle-ID/Pfad geraten.
