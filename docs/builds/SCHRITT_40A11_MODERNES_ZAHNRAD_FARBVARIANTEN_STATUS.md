# Schritt 40a11 – Modernes Zahnrad mit Farbvarianten

## Grundlage

Aufbauend auf Schritt 40a10.

## Änderung

- Das in 40a9 verwendete, kompakte Zahnrad-Design wurde wiederhergestellt.
- Einstellungen verwendet dasselbe Zahnrad in Grau.
- Administration verwendet dasselbe Zahnrad in Gold.
- Die unterschiedliche Bedeutung wird ausschließlich über Farbe und Rahmen hervorgehoben.
- Dashboard, Navigation und Login-Dialog verwenden weiterhin dieselben zentralen Icon-Dateien.

## Darstellung

- Einstellungen: graues Zahnrad (`#6b7280`)
- Administration: goldenes Zahnrad (`#d4a017`)

## Test

1. Browser mit `Strg+F5` vollständig neu laden.
2. Dashboard öffnen.
3. Prüfen, dass Einstellungen und Administration dieselbe Zahnradform verwenden.
4. Prüfen, dass Einstellungen grau und Administration gold dargestellt werden.
5. Darstellung zusätzlich im Login-Dialog und in der Navigation prüfen.
