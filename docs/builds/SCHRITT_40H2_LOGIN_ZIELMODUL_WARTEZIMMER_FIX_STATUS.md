# Schritt 40h2 – Login-Zielmodul Wartezimmer

## Korrektur

- `Wartezimmer` in die sichtbare Login-Anwendungsliste aufgenommen.
- Zuordnung zum internen Seiten-Schlüssel `waitingRoom` bestätigt.
- Zusätzliche Startseiten-Aliase für `Wartezimmer`, `Waiting Room`, `WaitingRoom` und `Patientenfluss` ergänzt.
- Login-Auswahl und Navigation verwenden weiterhin dasselbe Wartezimmer-Symbol.

Damit kann das Wartezimmer direkt im Logindialog gewählt und nach erfolgreicher Anmeldung als Zielmodul geöffnet werden.
