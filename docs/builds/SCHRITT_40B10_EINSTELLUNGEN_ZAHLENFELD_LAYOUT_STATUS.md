# Schritt 40b10 – Einstellungs-Zahlenfelder Variante 1

## Umgesetzt

- Zahlenfelder besitzen eine feste, kompakte Breite.
- Beschriftungen stehen links, Werte rechts in einer einheitlichen Spalte.
- Einheiten wie Sekunden, Tage, Euro und Prozent stehen außerhalb des Eingabefeldes.
- Die nativen Mehr-/Weniger-Schaltflächen bleiben erhalten.
- Kein Eingabefeld ragt mehr über den Rahmen der jeweiligen Einstellungskarte hinaus.
- Derselbe Standard gilt für Allgemein und die Workflow-Einstellungen.
- Responsive Darstellung für schmalere Fenster bleibt erhalten.

## Prüfung

1. Einstellungen → Allgemein öffnen.
2. Kontrollieren, dass die Sekundenwerte vollständig lesbar sind.
3. Prüfen, dass alle Zahlenfelder innerhalb ihrer Karten bleiben.
4. Einstellungen → Workflows → Zahlungsworkflow öffnen.
5. Ausrichtung der Zahlenfelder und Einheiten kontrollieren.
