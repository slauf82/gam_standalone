# Schritt 38e3 – Modale Bearbeitungsdialoge wie GAM 1.0

## Ziel

Die Bearbeitung langer Listen soll ohne manuelles Scrollen möglich sein. Die Formularbereiche werden deshalb als schwebende Dialoge über der Seite dargestellt.

## Umgesetzt

- Geräteverzeichnis: Neues Gerät und Eintrag-Auswahl öffnen einen modalen Dialog.
- Lagerverwaltung: Neuer Eintrag und Eintrag-Auswahl öffnen einen modalen Dialog.
- Modul-Administration: Neu und Bearbeiten öffnen einen modalen Dialog.
- Hintergrund wird abgedunkelt.
- Klick auf den abgedunkelten Hintergrund schließt den Dialog wie Abbrechen.
- Schließen über X und Abbrechen möglich.
- Speichern/Anlegen bleibt eine aktive Benutzerentscheidung.
- Keine Backend-, Datenbank- oder API-Änderungen.

## Hinweis

Schritt 38e2 mit reiner Scroll-Navigation wurde durch diesen GAM-1.0-näheren Dialogansatz funktional überholt.
