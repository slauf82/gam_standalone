# Schritt 40k35h1 – Abstand vor App-Zählern

Kleiner UI-Feinschliff im Bereich „Registriert“:

- „Benutzer-Apps(100)“ wird als „Benutzer-Apps (100)“ dargestellt.
- „System-Apps(255)“ wird als „System-Apps (255)“ dargestellt.
- Auch Android-Benutzerprofile wie „Hauptbenutzer (100)“ verwenden denselben Abstand.

Es wurden keine Backend- oder Datenbankänderungen vorgenommen.
