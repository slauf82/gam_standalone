# GAM 2.0 – Schritt 40k36j

## Plattformübergreifend: Datenträger & Verschlüsselung

- Gemeinsamer Gerätebereich für Windows, Linux und macOS.
- Einheitliche Begriffe für Systemschutz, Verschlüsselungsübersicht, Datenträger/Volumes, Sperrstatus und Diagnose.
- Plattformtechnologien bleiben sichtbar: BitLocker, LUKS/dm-crypt sowie FileVault/APFS.
- Im registrierten Gerätebaum werden Storage- und Verschlüsselungsdaten in einer gemeinsamen Kategorie gruppiert.
- Betriebssystemspezifische Detaildaten bleiben vollständig erhalten.
