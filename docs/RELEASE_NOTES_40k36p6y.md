# 40k36p6y – Direkte Verbindungstestergebnisse

- Windows WinRM zeigt Ergebnis, Ziel, Zeitpunkt und Antwortzeit direkt im Betriebssystemzugang.
- Linux/macOS SSH zeigt den gemeinsamen SSH-Test direkt im Betriebssystemzugang.
- Android ADB zeigt Status bzw. Verbindungsprüfung direkt im Betriebssystemzugang.
- Laufende Prüfungen, Erfolg und Fehler sind optisch unmittelbar unterscheidbar.
- Testergebnisse bleiben über die vorhandene Quellen-Testpersistenz sichtbar; WinRM hält das aktuelle Ergebnis bis zum nächsten Test.
