# 40k36t5

- Plattformläufe folgen nach verifizierter Inventarisierung der kanonischen Geräteidentität.
  Dadurch bleibt insbesondere eine Startinventarisierung in der Plattforminventarisierungstabelle sichtbar,
  auch wenn Linux-SSH während des Laufs Name/Plattform/Identität präzisiert.
- Linux-Startinventarisierung und manuelle Inventarisierung verwenden denselben verifizierten Speicherpfad.
- Laufzeitdiagnose mit `[LINUX-TIMING]` für:
  - Vorprüfung/Netzwerkdienste
  - SSH-Inventarbefehl inklusive Übertragung/Parsing
  - Nachverarbeitung
  - Identitätspersistierung
  - Softwarepersistierung
  - Gesamtlauf
- Software-Unterkategorien/Quellen werden in der registrierten Geräteansicht sichtbar eingerückt.
