# 40k36p6t – Merge 2.0: Mehrfach-IP/MAC und Wiederauftrennung

Zusammengeführte Geräte bleiben ein kanonisches Gerät, behalten aber alle bekannten Netzwerkidentitäten. Mehrere IP- und MAC-Adressen werden direkt im Gerätemanager sichtbar und stehen der späteren Wiedererkennung zur Verfügung. Frühere Merges werden aus den vorhandenen Merge-Schnappschüssen rückwirkend ergänzt. Das Aktionsmenü bietet bei zusammengeführten Geräten nun die geführte Wiederauftrennung.
