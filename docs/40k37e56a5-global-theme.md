# 40k37e56a5 – globale GAM-Designwahl

- Neue Einstellung unter **Einstellungen → Allgemein → Design**.
- Auswahl: **Helles Design** oder **Dunkles Design**.
- Standard für neue/noch nicht konfigurierte Browser ist **Helles Design**.
- Auswahl wird lokal im Browser gespeichert und sofort auf die gesamte GAM-Oberfläche angewendet.
- Die Designwahl überschreibt die Betriebssystem-Vorgabe bewusst.
- GAM-Kontrastregel: helles Design = dunkle Schrift auf hellen Flächen; dunkles Design = helle Schrift auf dunklen Flächen.
- Keine Änderungen an Discovery-, Inventarisierungs-, Merge- oder Apple-Logik.
