# 40k36s2
- Erststart-Assistent: Status und Installationsaktion für Homebrew, MariaDB, smartmontools und mas.
- Installationen werden sichtbar im macOS-Terminal gestartet, damit Passwort-/Homebrew-Rückfragen beim Benutzer bleiben.
- MariaDB wird nach Installation als Homebrew-Dienst gestartet.
- Registrierte Gerätekategorien können mit einer bestätigten Massenaktion deregistriert werden; andere Kategorien bleiben unberührt.
