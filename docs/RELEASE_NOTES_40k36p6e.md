# 40k36p6e – Typografie der Erkennungsquellen

- Quellenname und technische Beschreibung erscheinen mit einem klaren Mittelpunkt-Abstand.
- Status, letzter Test und Inventarisierung besitzen mehr Abstand zwischen Bezeichnung und Wert.
- Das bewährte Muster des Registrierungsmodus dient als typografische Vorlage.
