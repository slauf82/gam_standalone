# Piper-Stimmenauswahl – Ziel für Schritt 36g

Ziel: je UI-/TTS-Sprache soll langfristig mindestens eine weibliche und eine männliche Stimme auswählbar sein.

Die vorhandene Auto-Download-Logik bleibt bestehen. Für v1.7.1 sollte die Oberfläche später optional anbieten:

- automatische Stimme
- weibliche Stimme
- männliche Stimme

Wenn eine gewünschte Stimme fehlt, soll GAM sie wie bisher automatisch herunterladen und bis dahin Browser-TTS als Fallback verwenden.

Hinweis: Die konkrete Zuordnung hängt von den tatsächlich verfügbaren Piper-Voice-Modellen ab und sollte vor der finalen Aktivierung pro Sprache getestet werden.
