# 40k36q14 – Merge-Hinweis in Gerätezeile

- Der lange Text `Konflikt offen / Zusammenführung prüfen` wird in registrierten Gerätezeilen nicht mehr ausgegeben.
- Bei offenem Merge-Kandidaten erscheint stattdessen das kompakte Badge `⚠ Merge prüfen`.
- Das Badge besitzt einen Tooltip: `Möglicher Identitätskonflikt – Zusammenführung prüfen`.
- Klick auf das Badge öffnet direkt die Identitäts-/Zusammenführungsprüfung des betroffenen Geräts.
- Ohne offenen Merge-Kandidaten bleibt die normale Confidence-Anzeige bestehen.
- Ziel: bessere Lesbarkeit insbesondere bei Multi-Interface-Geräten wie gleichzeitigem Ethernet- und WLAN-Zugang.
