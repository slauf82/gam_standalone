# Schritt 40k36n – Linux-Berechtigungen und Inventarisierungstiefe

- Erkennung von Benutzer, UID, Gruppen und Administratorgruppen
- Erkennung von sudo-Verfügbarkeit, kennwortlosem sudo und Root-Kontext
- Einheitliche Inventarisierungsstufen: Standard, Erweitert, Administrator, Vollzugriff
- Verständliche berechtigungsbedingte Einschränkungen
- Optionaler einmaliger erhöhter Inventarlauf mit sudo-Kennwort
- Kennwort wird nur über stdin an sudo übertragen, nicht gespeichert und nicht protokolliert
