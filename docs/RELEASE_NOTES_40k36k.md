# GAM 2.0 – Schritt 40k36k

## Verbindungsmanagement 2.0

Android, Windows, Linux und macOS verwenden nun einen gemeinsamen sichtbaren Statuskopf. Einheitlich angezeigt werden Plattform, aktueller Zustand, technischer Hintergrund, Zielsystem, letzte erfolgreiche Verbindung beziehungsweise Prüfung und eine verständliche Handlungsempfehlung.

- Android: ADB-Verbindung, Pairing, Wiederverbindung und Inventarisierung
- Windows: WinRM-/PowerShell-Konfiguration und Verbindungstest
- Linux: SSH-Konfiguration, Verbindungstest und Inventarisierung
- macOS: SSH-Konfiguration, Freigabeanleitung, Verbindungstest und Inventarisierung
- gemeinsame Statusbegriffe und Statusfarben
- zentrale Scroll-/Fokusführung bleibt erhalten
- technische Protokolle bleiben als Hintergrundinformation sichtbar, sind aber nicht mehr das primäre Bedienkonzept
