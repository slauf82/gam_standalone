# 40k36q6 – Vollständige Inventarisierung als Standard

- Die sichtbare Auswahl Basis / Standard / Vollständig wurde aus den Erkennungsquellen entfernt.
- Für den normalen Benutzerworkflow verwendet GAM jetzt grundsätzlich die vollständige Inventarisierung.
- Die Oberfläche zeigt nur noch `Inventarisierung: Vollständig`.
- In der Diagnose wird `Vollständige Prüfung (Standard)` angezeigt.
- Interne Status-/Tiefenbegriffe bleiben für technische Abläufe und historische Daten bestehen.
- Fehlende Berechtigungen führen weiterhin zu Hinweisen bzw. Teilresultaten; ein erneuter Lauf mit erhöhten Rechten kann fehlende Daten ergänzen.
