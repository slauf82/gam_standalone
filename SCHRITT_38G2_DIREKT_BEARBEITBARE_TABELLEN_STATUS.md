# Schritt 38g2 – Direkt bearbeitbare Tabellenzeilen

## Ziel

Die Bedienung der neuen GDS-Module wird korrigiert: Datensätze sollen direkt aus der Tabelle heraus bearbeitbar sein. Separate Listen unterhalb der Tabelle entfallen.

## Umgesetzt

- Aufgabenverwaltung: Tabellenzeile direkt anklickbar, zusätzlicher Bearbeiten-Button.
- Freigabemanagement: Tabellenzeile direkt anklickbar, zusätzlicher Bearbeiten-Button.
- Bestelltool: Materialzeile erzeugt direkt einen Bestellentwurf; Entwurfszeile öffnet direkt die Bearbeitung.
- Modul-Administration: separate Aktionsliste entfernt; jede Tabellenzeile öffnet direkt den Bearbeitungsdialog.
- Einheitliche visuelle Rückmeldung für anklickbare Zeilen.

## Keine Änderungen

- Keine Datenbankänderungen.
- Keine API-Änderungen.
- Keine generierten Ordner im Austauschpaket.
