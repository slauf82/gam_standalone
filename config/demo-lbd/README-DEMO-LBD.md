# Demo-LBD-Dateien

Diese Dateien enthalten ausschließlich synthetische Demo-Daten.

Standard-Demo-Datei:

```text
config/demo-lbd/max.mustermann.lbd
```

Sie dient als Fallback für Demo-Installationen, damit Rechnungsvorschau, PDF, ZUGFeRD-Prüfung und QR-Rechnungsportal ohne zusätzliche LBD-Konfiguration getestet werden können.
