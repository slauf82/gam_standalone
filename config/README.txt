Hier kann eine bestehende .lbd-Datei für das Rechnungsmodul abgelegt werden.

Standardsuche:
1. GAM_LBD_FILE, falls gesetzt
2. ./config/*.lbd
3. ./daten/rechnung/*.lbd
4. Projektwurzel/*.lbd

Das Format bleibt kompatibel zum Altprojekt:
3000 Patientennummer
3100 Namenszusatz
3101 Nachname
3102 Vorname
3103 Geburtsdatum
3104 Titel
3105 Versichertennummer
3106 PLZ Ort bzw. Land
3107 Straße
3108 Versichertenart
3110 Anrede
