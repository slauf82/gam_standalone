# Schritt 40a6 – Einstellungsmodul vollständig registriert

- Einstellungen im Login-Dialog auswählbar
- direkter Login in das Einstellungsmodul möglich
- Einstellungen als gültiges hartes Login-Ziel registriert
- Einstellungen im Dashboard/Modulstatus sichtbar
- Einstellungen in Admin-/Superadmin-Modulrechten enthalten

## Test
1. Login-Dialog öffnen und „Einstellungen“ auswählen.
2. Per Passwort, TOTP oder Passkey anmelden.
3. Direkter Einstieg muss im Modul Einstellungen erfolgen.
4. Dashboard öffnen; Einstellungen muss in der Modulübersicht erscheinen.
5. Prüfungsschritt ändern, speichern, Seite und Backend neu starten und Persistenz prüfen.
