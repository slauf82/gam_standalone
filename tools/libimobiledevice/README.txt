GAM 40k37c3 - portable libimobiledevice Toolchain

Unter Windows kann GAM die benoetigte Toolchain ueber die Oberflaeche
"Pairing-Werkzeuge installieren" direkt in dieses Verzeichnis laden.

Gepinnte Quelle:
https://github.com/jrjr/libimobiledevice-windows
Release: v20260906-74585f8

Pflichtwerkzeuge nach erfolgreicher Installation:
- idevice_id.exe
- idevicepair.exe
- ideviceinfo.exe
- alle von der Distribution mitgelieferten DLLs

Es sind weder PATH-Aenderung noch Installation unter C:\Program Files erforderlich.
