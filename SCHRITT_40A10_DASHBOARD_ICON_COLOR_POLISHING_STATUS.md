# Schritt 40a10 – Dashboard Icon Color Polishing

## Basis

Erstellt auf Grundlage von Schritt 40a9.

## Änderungen

- **Einstellungen** verwendet jetzt ein graues Zahnrad.
- **Administration** verwendet jetzt ein gelb/goldenes Zahnrad.
- Die Symbolform bleibt bewusst ähnlich, während die Farbe die unterschiedlichen Aufgabenbereiche eindeutig kennzeichnet.
- Darstellung gilt überall dort, wo die zentralen Modul-SVGs verwendet werden, insbesondere im Login-Dialog, in der Navigation und im Dashboard.
- Keine Änderung an Fachlogik, Datenbank oder Berechtigungen.

## Prüfen

1. Login-Dialog öffnen:
   - Einstellungen: graues Zahnrad
   - Administration: goldenes Zahnrad
2. Nach dem Login Navigation prüfen.
3. Dashboard prüfen.
4. Browser-Cache bei Bedarf mit `Strg+F5` neu laden.
